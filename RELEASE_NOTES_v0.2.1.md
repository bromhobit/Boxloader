## Boxloader 0.2.1 — нормальная установка в Linux

Переработан интерфейс настольного установщика IPA и добавлены готовые релизные сборки. Проект больше не зависит от временных каталогов Codex.

### Изменения

- Удалены неработающие вкладка **Dopamine Renew / Rebox**, механизм USB-продления и отдельная кнопка **«Залить pairing-файл в SideStore»**.
- Оставлены установка `.ipa`, Apple ID / 2FA, подключение iPhone по USB, настройка Sidebox и журнал действий.
- Нативный ELF-запускатель на **Rust**, интерфейс на PySide6, USB-движок на Rust.
- Сессия Apple ID хранится локально в защищённом каталоге `~/.local/state/boxloader/apple-session/`, а не в исходниках или каталоге Codex.
- Исправлены пути к ресурсам для пользовательской и системной установки; приложение запускается через меню KDE.
- Добавлены пакеты для Arch/CachyOS, Debian-совместимых Linux и AppImage.

### Скачать и установить

- **Arch Linux / CachyOS:** `boxloader-0.2.1-1-x86_64.pkg.tar.zst` — `sudo pacman -U ./boxloader-0.2.1-1-x86_64.pkg.tar.zst`.
- **Debian / Ubuntu (экспериментально):** `boxloader_0.2.1-1_amd64.deb` — `sudo apt install ./boxloader_0.2.1-1_amd64.deb`. Требуется Python 3.14 и PySide6; в обычных стабильных выпусках дистрибутивов они могут отсутствовать.
- **AppImage (экспериментально):** `Boxloader-0.2.1-x86_64.AppImage` — сделайте файл исполняемым и запустите. Включён Python 3.14 / Qt 6; проверено на CachyOS, совместимость со старыми дистрибутивами не гарантируется.

**Проверки:** 13 автоматических тестов GUI, проверка `--self-test` у ELF, Arch/DEB после распаковки и AppImage. Подпись IPA и работа с Apple Developer не проверялись заново в этом релизе.

🔒 Сессии Apple ID, пароли, pairing-файлы и профили подписи в пакеты не включены.
